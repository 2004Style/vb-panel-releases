# VB Panel: releases

Instalador (`deploy.sh`), paquetes compilados y `SHA256SUMS` firmado de VB Panel.
El código fuente vive en un repositorio privado; este repositorio solo contiene releases.

Instalación: `curl -fsSL https://github.com/2004Style/vb-panel-releases/releases/latest/download/deploy.sh | bash`
